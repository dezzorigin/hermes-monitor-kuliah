Papan status monitor

Status di bawah ini contoh dari satu run cron — landing ini etalase; automation-nya jalan di server.

Gerbang absen

Di luar jendela

absen_gate.py jalan tiap 10 menit. Di luar jendela kuliah output-nya konstan idle — agent tidak bangun. Di dalam jendela, output berubah tiap tick dan agent mengecek halaman absensi.

Jendela gerbang

Jendela cek jadwal
mulai −15 mnt s/d mulai +30 mnt
Contoh gate aktif

Alur sekali absen

Hadir
  1. Login SIMKULIAH — session + captcha 5 digit dipecahkan lokal dengan ddddocr, retry sampai 6 kali.
  2. Baca halaman absensi — parser mengenali tombol konfirmasi-kehadiran-* (format var 2026 + legacy).
  3. POST konfirmasi langsung — ke /absensi/konfirmasi_kehadiran, tanpa mengandalkan klik dialog SweetAlert.
  4. Verifikasi ulang — tombol hilang + respons success, lalu MK dicatat di absen_state.json.

Monitor tugas

Menunggu dosen

Cron monitor-tugas-dezz mengecek Moodle USK dan Google Classroom 4 kali sehari. Tugas baru dilaporkan sekali; yang hash instruksinya sama dilewati (dedupe di state.json). Kuis dan ujian hanya dilaporkan — tidak pernah dikerjakan otomatis. Tugas tidak pernah di-submit tanpa konfirmasi.
